# Glow And Gather Portfolio

A minimalist portfolio for a front-end developer, built with React. It includes
light and dark themes, animations, and project highlights.

## Development

Install dependencies and run the development server with npm:

```powershell
npm install
npm start
```

Or use [Bun](https://bun.sh/):

```powershell
bun install
bun run dev
```

Open the localhost URL printed in the terminal.

## Deploy to GitHub Pages

Push changes to `main` to build and deploy the static site with GitHub Actions.
In the repository's **Settings → Pages**, set the source to **GitHub Actions**.
The site will be available at `https://xeltyx.github.io/MyPortfolio/`.
