# Glow And Gather Portfolio

A minimalist portfolio for a front-end developer, built with React. It includes
light and dark themes, animations, and project highlights.

## Development

Install dependencies and run the development server with npm:

```powershell
npm install
npm start
```

Or use [Bun](https://bun.sh/):

```powershell
bun install
bun run dev
```

Open the localhost URL printed in the terminal.

## Deploy to GitHub Pages

Build and publish the static site to the `gh-pages` branch:

```powershell
npm run deploy
```

In the repository's **Settings → Pages**, choose **Deploy from a branch**, then
select the `gh-pages` branch and `/ (root)`. The site will be available at
`https://xeltyx.github.io/MyPortfolio/`.
