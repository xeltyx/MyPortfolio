# Glow And Gather Portfolio

A minimalist portfolio for a front-end developer, built with React. It includes
light and dark themes, animations, and project highlights.

## Development

Install dependencies and run the development server with npm:

```powershell
npm install
npm start
```

Or use [Bun](https://bun.sh/):

```powershell
bun install
bun run dev
```

Open the localhost URL printed in the terminal.

## Deploy to Vercel

Import the repository into Vercel. The included `vercel.json` builds the
prerendered site and publishes `dist/client`. Pushes to the connected branch
will deploy automatically.
